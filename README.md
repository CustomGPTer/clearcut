# Clearcut

Clearcut is a free background remover for Android. One tap cuts the subject out of a photo, and hand tools tidy the rest. Save it see-through, put something new behind it, or make it a WhatsApp sticker. The work is done on the phone, so photos are never uploaded. It has no adverts, no accounts and no paid version.
